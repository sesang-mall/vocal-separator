# 사과게임 10·20·30

격자의 사과를 드래그로 묶어, 숫자 합이 **10, 20, 30** 중 하나이면 지우는 2분 제한 퍼즐입니다. 폰·태블릿·PC 브라우저에서 동작합니다.

## 실행

빌드가 필요 없는 정적 파일입니다.

```bash
cd apple-game
python3 -m http.server 8000
```

같은 Wi-Fi의 폰이나 태블릿에서 `http://<PC의 IP>:8000` 으로 접속하세요. 파일을 직접 열어도 되지만, 홈 화면에 추가하려면 http(s)로 열어야 합니다.

## 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 반응형 레이아웃, 라이트/다크 테마 |
| `game.js` | 규칙, 드래그 입력, 타이머, 최고 점수 저장 |
| `manifest.webmanifest`, `icon.svg` | 홈 화면에 추가할 때 쓰는 앱 정보 |

## 모바일·태블릿 대응

- Pointer Events 하나로 터치·마우스·펜을 같이 처리하고, 첫 손가락만 인식합니다.
- 보드에 `touch-action: none`을 적용해 드래그 중 화면이 스크롤되거나 확대되지 않습니다.
- 보드는 17:10 비율을 유지한 채 화면 가로·세로 중 작은 쪽에 맞춰 커져서, 세로·가로 방향 모두 스크롤 없이 한 화면에 들어옵니다.
- 노치와 홈 바 영역은 `safe-area-inset`으로 피합니다.
- 합이 맞으면 짧게 진동합니다(지원 기기만).

## 규칙 바꾸기

`game.js` 맨 위의 `COLS`, `ROWS`, `TIME`, `TARGETS`를 고치면 됩니다. 격자 크기를 바꿀 때는 `style.css`의 `--cols`, `--rows`도 같이 바꾸세요.
